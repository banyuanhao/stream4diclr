# Stream4D: 4D-Consistency for Streaming Autoregressive Diffusion Video Models

Anonymous project page for the paper *Stream4D: 4D-Consistency for Streaming Autoregressive Diffusion Video Models* (under review).

Open `index.html` in a browser to view the page, including the teaser, method overview, quantitative highlights, and side-by-side video comparisons against Base, World-R1, and VideoGPA.
